# Claude Code 共通設定

このファイルは `~/.claude/CLAUDE.md` に配置され、全プロジェクトで適用される。
プロジェクト固有の設定は、各プロジェクトの `.claude/CLAUDE.md` で上書き可能。

## 言語

- 日本語で応答する
- コード内のコメントは英語（国際的なプロジェクトを想定）
- 技術用語は英語のまま使用可

## コーディングスタイル

### 全般

- シンプルさを優先する
- 過剰な抽象化を避ける
- 既存のコードスタイルに従う
- ソースコメントは基本的につけない（過剰にコメントをつけるとメンテコストが上昇し、誤った情報をAIが読み取るため、ロジックはコードで意図を表現するようにする）
  - TODOコメントや、必要不可欠であると判断した場合のみコメントを付与する
  - プロジェクトに慣習的なコメントの付け方がある場合のみそれに従う

### Git

- コミットのルールは `/commit` スキルに定義
- PR は draft で作成する
- reviewer は勝手に設定しない（明示的な指示がある場合のみ設定する）

### ドキュメント

- `docs/` ディレクトリに Markdown で作成
- mermaid で図を作成
- 参照URLには引用文を併記

## 作業フロー

1. 変更前に既存コードを確認する
2. 実装時に不明な点があれば、勝手に解釈せず質問して解決してから実装に入る
3. 小さな変更から始める
4. 動作確認してからコミットする
5. 大きな変更は計画を立ててから実行する

## 禁止事項

- 明示的な指示なく `.env` や認証情報を含むファイルを操作しない
- 破壊的な git 操作（`--force`, `reset --hard`）は確認なく実行しない
- `--no-verify` で pre-commit フックを回避しない（検知時は内容を報告して指示を仰ぐ）
- 本番環境への直接操作は行わない
