# Claude Code 共通設定

このファイルは `~/.claude/CLAUDE.md` に配置され、全プロジェクトで適用される。
プロジェクト固有の設定は、各プロジェクトの `.claude/CLAUDE.md` で上書き可能。

## 言語

- 日本語で応答する
- コード内のコメントは英語（国際的なプロジェクトを想定）
- 技術用語は英語のまま使用可

## コーディングスタイル

### 全般

- シンプルさを優先する
- 過剰な抽象化を避ける
- 既存のコードスタイルに従う
- 不要なコメントを追加しない（コードで意図を表現する）

### Git

- コミットメッセージは英語
- Conventional Commits 形式を使用: `type(scope): description`
- 1コミット1目的

### ドキュメント

- `docs/` ディレクトリに Markdown で作成
- mermaid で図を作成
- 参照URLには引用文を併記

## 作業フロー

1. 変更前に既存コードを確認する
2. 小さな変更から始める
3. 動作確認してからコミットする
4. 大きな変更は計画を立ててから実行する

## 禁止事項

- 明示的な指示なく `.env` や認証情報を含むファイルを操作しない
- 破壊的な git 操作（`--force`, `reset --hard`）は確認なく実行しない
- 本番環境への直接操作は行わない
